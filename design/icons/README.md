# Mood desktop icons

30 editable SVG glyphs, 24 x 24 units, 1.8-unit rounded strokes.

Figma sheet: https://www.figma.com/design/CVShvpjFqcn7JkuIV5GHXX/Mood---UI-Discord-Calage?node-id=176-9

These are design assets. Runtime controls currently use SF Symbols; the SVG set is not yet wired into SwiftUI. The Mood infinity glyph is a navigation exploration, not a replacement for the existing animated logo. Server glyphs are placeholders for demo communities, not replacements for user-uploaded avatars.

Keep the viewBox and stroke proportions when exporting. Apply the app's semantic foreground color at the integration point. Review optical weight at 16, 20, and 24 points before substituting a native symbol.
